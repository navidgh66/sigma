sigma 0.30.0 makes research Claude + Codex only, signs in to Codex with a device code, and makes `sigma doctor --update` honest when the CLI can't update.

## Changed
- **Codex sign-in uses the device-code flow** (`codex login --device-auth`) in `sigma onboard` and the `sigma doctor` fix. It prints a URL and a one-time code you approve in any browser, so it works on a laptop, over SSH and in cloud sessions.
- **`sigma doctor --update` reports a refused CLI pull.** When `git pull` fails (for example because of local edits in `~/.sigma`), it now prints `✗ CLI update failed` with the exact fix (`git -C ~/.sigma stash && sigma doctor --update`). On success it prints the version actually on disk (`✓ CLI now at 0.30.0`), because the running process still has the old code loaded.

## Removed
- **Gemini** is gone from sigma: the research adapter, the `GEMINI_API_KEY` secret, the doctor and onboard checks, the gemini researcher persona, and the `/research` dispatch step. Research now fans out to Claude and GPT (via `codex exec`), plus the optional Firecrawl search tier.
- Existing `sigma.config.yml` files that still list `gemini` keep working: it is dropped on load.

## Migration
- A stale `GEMINI_API_KEY` in `~/.sigma/.env` is ignored; delete the line if you like.
- If you installed the gemini CLI only for sigma: `npm uninstall -g @google/gemini-cli`.

## Verification
- 662 pytest tests pass and ruff is clean. `sigma docs-check --check` passes.
- `tests/test_no_gemini.py` keeps Gemini from coming back, and checks that an old config listing it still loads.
