sigma 0.29.0 drops caveman. sigma no longer installs, checks or bundles it.

## Removed
- `cli/caveman.py` and the `caveman` doctor check (`sigma doctor` no longer offers to install it).
- `sigma onboard` step 7 (caveman setup); the later steps are renumbered.
- The vendored `skills/vendor/caveman` skill.
- Caveman mentions in the `sigma-cost` / `sigma-prune` skills, `/prune`, and the docs.

## Migration
sigma never removes things it didn't install without asking, and caveman lives in your global Claude Code setup, so remove it yourself if you want it gone:
- Plugin: `claude plugin uninstall caveman@caveman`
- Standalone skill copy (if you added one with `npx skills add`): `rm -rf ~/.claude/skills/caveman`
- Restart Claude Code afterwards.

## Verification
- 660 pytest tests pass and ruff is clean. `sigma docs-check --check` passes.
- A new test (`tests/test_no_caveman.py`) keeps caveman from coming back through the CLI, commands, skills or docs.
