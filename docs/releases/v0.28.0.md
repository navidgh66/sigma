sigma 0.28.0 makes `/loop` a real in-session loop built on the Opus 5.5 prompting guide, and removes the CLI features that only served the old autonomous engine.

## Added
- **In-session `/loop`** runs every open task in `tasks.md` to done. Per task: test snapshot → `sigma-implementer` → tamper check → `sigma-verifier` → `sigma-e2e` for tagged scenarios. Up to 2 retries, then the task is marked failed and a lesson is written.
- **Role agents** (`agents/`) with their own `effort` and tool lists. The verifier and e2e agents have no Edit/Write tools, so maker ≠ checker is enforced by tool permissions.
- **Stop hook** (`hooks/loop_guard.py`) reads `loop-state.json`. While tasks are open and nothing blocks them, it sends the session back to work. It nudges at most 3 times without progress and fails open on any error. This follows the Opus 5.5 guide: a text-only end of turn is a report, not proof the work is done.
- **Test tamper guard** (`scripts/test_guard.py`): an attempt fails if it edits or deletes a test that already existed, and `restore` puts the originals back.
- **Untrusted-text guardrail** on `/craft` (pasted designs), `/research` (manual findings, web results) and `/review` (other people's diffs).

## Changed
- Lesson recall is capped at the **5 newest per domain**, and lessons carry a `created:` date. A same-titled lesson no longer overwrites the earlier one; it goes to `<slug>-2/` and is flagged as a contradiction.
- The ratchet moved to `cli/ratchet.py`.
- The LLM-engineering and agent-engineering domain guides are rewritten for the Claude 5 family:
  - effort replaces "think step by step"
  - `reasoning_extraction` refusals
  - `max_tokens` headroom
  - unattended-run patterns
  - time-budget signals
- Commands and skills use plain wording instead of stacked capitals.
- CLAUDE.md went from 807 lines to 149.

## Removed
- CLI `sigma loop`, `hermes`, `board`, `weave`, `eval`, `lessons`, `trajectory` (including `--economy`), and `launch`, plus their modules and the `/hermes`, `/board`, `/weave` and `/eval` commands. About 3,800 lines of Python.
- The loop's advisor and simplifier roles. Retries now use the verifier's findings, and Claude Code's built-in `/simplify` covers cleanup.
- Telemetry and trajectory plumbing in `AgentRunner`.

## Migration
- `sigma loop --execute` users: run `/loop` in Claude Code instead. Ask for "TDD" or "in parallel" in plain words.
- `sigma hermes --auto`: run the stages in-session, or use `/craft` from a design.
- Bare `sigma` now prints help.

## Verification
- 673 pytest tests pass and ruff is clean. `sigma docs-check --check` passes.
- `claude plugin validate` passes for the manifest, agents, commands and skills.
- Live test: with the plugin loaded and one open task in `loop-state.json`, `claude -p "Reply with just the word: ready"` was sent back by the Stop hook, did the task, marked it passed, then stopped.
- Every task was reviewed by Codex as the second reviewer. Its findings are fixed in this release.
